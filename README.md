## Preview static exercises

From the repository root with Python 3:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/Web_Development/homework4/` or `http://127.0.0.1:8000/homework6/`. The static server does not execute PHP. The PHP starter contains placeholder database credentials and is not configured as a running backend. No whole-archive browser or correctness suite was run for this documentation update.

The two responsive-exercise directories are preserved as uploaded; their names alone do not establish which is the final submission.
